# Architecture Decisions

Records of significant architectural decisions made in this template. See the [ADR process](README.md) for how these are written and when to add a new one.

The decisions behind features this simple variant leaves out (background jobs, the transactional outbox, auditing, caching, file storage, ETags, API versioning, third-party sign-in) are recorded in the full template, [dotnet-angular-aspire-template](https://github.com/andregabrielmelo/dotnet-angular-aspire-template/tree/main/docs/content/architecture-decisions). Its numbers differ: its ADRs 010 and 014 are 008 and 009 here.
